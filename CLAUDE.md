# Case Room (사건 수사실)

A bilingual (Korean/English) yes-or-no deduction game for a church youth group (grades 6–12), served by GitHub Pages at https://youth-lcyg.github.io/case-room/ and by Vercel at https://lcyg-caseroom.vercel.app/ (project `lcyg-caseroom` in the LCYG team, linked to this repo: every push to `main` deploys both).

- All cases live in `cases.json`. To add or change a case, edit only that file, following `CASES.md` (content rules, Bible-case rules, picture rules).
- Run `python3 tools/validate.py` before committing; it must print OK.
- Commit to `main`. Pictures are made by hand in the Gemini app from the prompt list (each picture's `scene` plus the matching `pictureStyles` text) and saved in `images/` under the exact file names. The "Make pictures" workflow can still make missing pictures through the Cloudflare relay (secrets `RELAY_URL`, `RELAY_PASS`), but it runs only when started by hand, because pictures share the free daily Workers AI allowance with the AI judge and running out blocks the judge for about a day.
- "Make pictures with Gemini" (`.github/workflows/gemini-pictures.yml`, `tools/gemini_pictures.py`) makes the missing pictures with the Gemini API (secret `GEMINI_API_KEY`, an AI Studio key; billing appeared on the owner's Google Developer Program monthly credit). Start it only when the owner asks, and push nothing to `main` while it runs. It uploads the new pictures as a run artifact before pushing them. Check every new picture for text or numbers, and against its story, before reporting (two had lettering on 2026-11-01 and were touched up; on 2026-11-02 five of 22 were made again with clearer scenes and four were touched up: the model added people and menu boards, digits on padlock dials, lettering on packages and book spines, night instead of day, and ignored "upside down"). To make an existing picture again, pass its name in the job's `only` input.
- `index.html` and `make-pictures.html` read `cases.json` at runtime; don't paste cases into them.
- AI judging goes through the Cloudflare relay (`worker.js`, deployed by hand in the Cloudflare dashboard). Its address is built into the game as `RELAY_DEFAULT` in `index.html` (`https://case-room-judge.youth-bf0.workers.dev`); under "AI 연결" a device enters only the passcode, which is saved in that browser until "연결 해제".
- A mystery may also carry `adult`: the college-group version (original lateral-thinking stories with death, suicide or crime, no gore), with its own text, facts and pictures. No per-case content notes: they give away the answer (the owner's decision). A youth/college switch on the mysteries shelf picks the stories: a new device starts on the college versions (the owner's choice), each device remembers its last choice, and `?group=college` always opens on the college versions. The host screen follows the players' screen; the Claude artifact carries the youth stories only. In the game its id is `<id>--adult`. A picture slot that names a youth slot (`"cover": "hint1"`) reuses that youth picture; a `{scene, check}` slot is a new picture saved as `images/<id>-adult-<slot>.jpg`. See `CASES.md`.
- The youth stories carry the youth group's own logo (the owner's request, 2026-11-01): in youth mode the header shows the LCYG logo in place of the magnifier mark, and the home kicker says LCYG made and runs the game (`kickerYouth`). College mode keeps the magnifier and the plain kicker. The logo is the owner's `lcyg-logo-trans.png` (the circle, 96 px), inlined in `index.html` as `LCYG_LOGO` so the Claude artifact shows it too.
- Cases must not be obvious (the owner's standard, 2026-11-02): the first explanation that comes to mind on hearing the setup must not be the answer, and the answer should be a mechanism (like the desert man's balloon and drawn matches), not "it turned out to be kindness". See "뻔하지 않게" in `CASES.md`. On 2026-11-02 four youth stories were replaced this way (`silent-call`, `slowest-horse`, `torn-card`, `bridge-keeper`); the college tellings of the replaced ones were kept as college-only cases (`lights-out`, `summer-punch`, `blank-exam`, `wrong-door-feast`).
- The youth Sea Turtle Soup keeps the original story and changes only what he ate (the owner's decision, 2026-11-02): he made his best friend promise never to feed him bugs, the friend served boiled cockroaches and grubs as "sea turtle soup" (the crunch was "turtle cartilage") and hid it for twenty years. Tried and dropped: the friend delaying the rescue to be a hero, a hidden emergency box (no reason for shock, no way to know), the father's share (a father makes the sacrifice obvious), the man's dog (too painful).
- Bible cases must be fun too (the owner, 2026-11-07): four added on 2026-11-06 (`unopened-gate`, `portion-set-aside`, `silver-cup`, `ask-him`) were taken down the next day because the setups named famous scenes or the answer was just "God told him" / "an angel freed him". A Bible case needs a lesser-known scene whose answer is a human mechanism (a test, a decoy, a copy, a code, a mistaken assumption); see "성경 사건도 뻔하지 않게" in `CASES.md`. The case limit (`maxCases` in `cases.json`) is 40 (raised from 30 on 2026-11-06). The live judge infers motives the text doesn't state (it said Joseph hid the cup "to test them"), so a motive the passage leaves open goes into `facts` as an explicit NOT_STATED line, not only into `notStated`.
- A mystery marked `"only": "adult"` is a college-only story (no youth telling, no `adult` part): its own fields are the college text, it shows only on the college shelf (in its place in the file order), and the Claude artifact leaves it out.
- Both shelves follow the order of `cases.json`; mysteries go famous-and-solid first (the owner's choice, 2026-11-01). Case numbers are the place on the shelf being shown, so youth and college numbers can differ; a room sends the owner's story choice to its players.
- Truths are short paragraphs, one per line (`\n`); a line that starts with “ is shown as dialogue. Keep `en` and `ko` line for line. The AI judge answers from `facts` only, so a detail added to a truth that players could ask about also goes into `facts`/`factsKo`.
- Each case also carries `factsKo` (and `notStatedKo` for Bible cases): the same lines as `facts`/`notStated` in Korean, shown on the host screen (`index.html?host`). When you change `facts` or `notStated`, change the Korean lines to match.
- Multiplayer rooms: `rooms/worker.js` (Cloudflare Worker + Durable Object, SQLite storage) is deployed by `.github/workflows/rooms.yml` with the secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`. The game connects to `ROOM_SERVER` in `index.html` (`https://case-room-rooms.youth-bf0.workers.dev`). The rooms server accepts only the site addresses in `ALLOWED_ORIGINS` (`rooms/wrangler.toml`); add any new site address there. The room owner's device runs the game and sends its state; players send intents. `qrcode.js` (MIT, vendored) draws the join QR code.
- Each rooms deploy also runs `rooms/smoke_test.py` against the live server (owner and player connect, messages both ways); the results appear as notes on the Actions run.
- To test rooms locally: run `npx wrangler dev --var ALLOWED_ORIGINS:http://127.0.0.1:8765` in `rooms/`, serve the site on port 8765, and open it with `?server=http://127.0.0.1:8787`.
- The game's owner is a youth pastor who writes in Korean. Talk with him in Korean.
