그림 한꺼번에 만들기

게임에 연결한 Cloudflare AI로 표지와 힌트 그림을 한 번에 만듭니다. 이미 GitHub에 올라가 있는 그림은 건너뛰고, 다 만든 그림은 images 폴더가 든 ZIP 파일 하나로 내려받습니다.

쓰는 순서

  1. 오른쪽 칸에 중계 서버 주소와 암호가 있는지 봅니다. 이 브라우저에서 게임의 AI 연결을 해 두었다면 자동으로 채워져 있습니다.
  2. 모두 만들기를 누릅니다. 그림 한 장에 몇 초씩 걸립니다.
  3. 그림마다 확인 항목을 보고, 마음에 들지 않으면 다시 만들기를 누릅니다.
  4. ZIP으로 내려받기를 누르고, 내려받은 파일을 더블클릭해 압축을 풉니다. images 폴더가 나옵니다.
  5. GitHub 저장소에서 Add file → Upload files를 누르고 images 폴더를 통째로 끌어다 놓은 뒤 Commit changes를 누릅니다.

그림을 만들 때마다 Cloudflare의 하루 무료 AI 사용량을 씁니다. 46장을 다 만들면 하루 사용량의 많게는 절반쯤을 쓰니(추정), 게임하는 날 직전보다는 미리 만들어 두세요.

AI 연결

여기 넣은 주소와 암호는 이 브라우저에만 저장되고, 게임의 AI 연결과 함께 씁니다.
